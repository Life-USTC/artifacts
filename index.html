Current server reports

Open the server CI runs, choose the run for the commit or pull request you are reviewing, and inspect its checks. A report being available does not mean every check passed.

In the run's Artifacts section, download the relevant playwright-report-<domain> archive, extract it, and open index.html. GitHub requires sign-in to download artifacts. The server workflow currently retains these reports for 14 days; expired or cancelled runs may have no downloadable report.
